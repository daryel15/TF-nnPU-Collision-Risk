# Reference results

The six original CSVs were copied unchanged. Additional CSVs were recovered from saved notebook tables; their source cells and displayed precision are recorded in `table_provenance.json`. They are historical reference values, not newly executed training results.

`main_checkpoint_predictions.csv` is generated by verified evaluation of the supplied final model and is tied to the released dataset, main split and checkpoint hashes. `main_checkpoint_evaluation.json` records its metrics.

All future generated results go to `outputs/` and include per-run settings, keys, weights and predictions. See `../docs/EXPERIMENTS.md` for result mappings and limitations.
