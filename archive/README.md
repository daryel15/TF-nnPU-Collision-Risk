# Historical source archive

These Markdown documents preserve the supplied research notebook code and explanations. They are reference material, not executable release notebooks. The active notebooks are in `../notebooks/` and call the tested Python workflows.

Personal-machine paths, interactive state, unavailable file names, old plotting placeholders, and conditional raw-pipeline code remain visible here to explain provenance. Invalid pasted output rows in the historical full TF notebook were turned into comments. Do not copy and run the entire archive as one program. See `../docs/MISSING_ASSETS.md`.
